# Recipe Book

A simple and responsive recipe book website built with HTML, CSS, and JavaScript.

## About the Project

The Recipe Book helps users explore recipes, search by recipe name, filter recipes by category, view recipe details, and save their favourite recipes.

## Features

- View recipe cards with images and descriptions.
- Search recipes by name.
- Filter recipes by category.
- View ingredients and cooking instructions.
- Add and remove favourite recipes.
- Save favourite recipes using browser local storage.
- Show only favourite recipes.
- Responsive layout for different screen sizes.

## Technologies Used

- HTML5
- CSS3
- JavaScript
- Git
- GitHub

## Getting Started

1. Clone or download this repository.
2. Open the project folder.
3. Open `index.html` in a web browser.

No additional packages are required.

## How to Use

1. Open the website.
2. Browse the available recipes.
3. Use the search field to find a recipe by name.
4. Select a category to filter recipes.
5. Select **View Recipe** to see ingredients and instructions.
6. Select **Add Favourite** to save a recipe.
7. Enable **Show favourites only** to view favourite recipes.

## Data Storage

Favourite recipes are saved in the browser's local storage. The saved favourites are specific to the browser and website origin being used.

## Limitations

- Recipe information is based on sample data included in the project.
- Favourite recipes are not synchronised between different devices.
- The project does not use a backend database.
